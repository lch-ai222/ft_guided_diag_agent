# SOP：车机黑屏 EOL/售后诊断作业指导书

文档编号：SOP-IVI-BS-001  
适用范围：车机上电后无显示、黑屏、显示链路异常、刷写后无法启动。  
关联故障树：FT_001 车机黑屏故障树

## 1. 安全与前置条件
- 车辆处于 P 档，低压电源稳定，蓄电池电压应不低于 12.0V。
- 禁止带电插拔车机主机电源连接器和 LVDS 屏线。
- 涉及主板测量时必须断电 3 分钟以上，避免残余电压影响阻抗判断。

## 2. 初始确认
1. 执行 T001：确认上电后显示状态。
2. 记录屏幕是否完全无显示、是否有背光、是否有启动 LOGO、是否有触摸提示音。
3. 若仪表和车身模块均异常，应先排查整车低压电源，不进入本 SOP。

## 3. 供电链路排查
- 执行 T002：测量车机供电电压。
- B+、ACC、GND 必须同时确认，禁止只测 B+。
- 若输入电压异常，执行 T006 检查电源连接器插接状态。
- 若输入电压正常但车机无启动，执行 T005 检测电源管理芯片输出。
- 若 PMIC 输出异常且使能信号正常，可判定为电源管理芯片损坏候选。
- 若关键电源网络对地阻抗明显偏低，执行 T010，优先判断主板短路。

## 4. 显示链路排查
- 执行 T003：检查显示链路。
- 有触摸提示音但无可见亮度时，优先执行 T008 背光驱动输出检查。
- 有背光但无图像时，优先执行 T009 LVDS 屏线连接检查。
- 替换良品显示屏后恢复显示，可进入 S008 显示屏模组损坏分支。
- 屏线摇摆测试造成画面闪烁或黑屏，应进入 S010 LVDS屏线接触不良分支。

## 5. 软件启动排查
- 执行 T004：读取启动日志。
- 若日志中存在 boot loop、kernel panic、启动分区挂载失败，应保存日志包。
- 执行 T011：校验系统镜像完整性。
- 镜像校验失败时，允许按 S012 系统镜像损坏处理。
- 若镜像完整但仍反复崩溃，不允许直接更换硬件，应提交软件组分析。

## 6. 判定与放行
- 根因判定必须至少包含一个可复现检查项和一个闭环复测记录。
- 证据不足样例可标记 GRAY，不允许进入 PASS。
- 更换硬件后必须执行冷启动 3 次及 30 分钟老化观察。
