# 维修手册摘录：车门无法关闭

手册编号：RM-DOOR-CLOSE-001  
适用维修站：售后/PDI/返修  
关联故障树：FT_002

## 1. 症状分类
- A 类：车门可推至关闭位置，但门锁不上二道锁。
- B 类：车门关闭轨迹异常，出现擦碰或门缝不均。
- C 类：车门关闭阻力大，轻关回弹。
- D 类：电动门关闭中断、反弹或不吸合。
- E 类：门已关闭但仪表仍提示未关。

## 2. 工具
- 诊断仪
- 锁扣位置测量治具
- 间隙面差尺
- 门锁执行器驱动治具
- 万用表
- 密封条压缩检查工具

## 3. 标准维修流程
1. 记录故障门位和触发模式。
2. 检查门洞、密封条、锁扣是否有明显干涉。
3. 读取门锁状态和闭合传感器状态。
4. 检查门锁执行器动作及线束端子状态。
5. 需要调整锁扣或铰链时，记录调整前后数值。
6. 电动门问题必须完成初始化学习和防夹功能确认。

## 4. 维修动作
- S105：更换门锁执行器，并复测二道锁动作。
- S106：调整锁扣位置，涂色验证锁舌啮合居中。
- S107：校正或更换铰链，调整车门间隙。
- S108：重新装配或更换密封条。
- S109：更换闭合传感器，确认状态反馈一致。
- S110：升级或重刷车门控制模块软件，执行初始化学习。
- S111：修复门锁/传感器线束端子或更换线束。

## 5. 质量记录要求
维修单必须包含：关闭次数、是否进入二道锁、传感器状态、DTC/版本号、调整前后测量值、复测视频或照片。
