# 维修手册摘录：车机黑屏

手册编号：RM-IVI-BS-001  
适用维修站：售后/返修/PDI  
关联故障树：FT_001

## 1. 症状分类
- A 类：完全黑屏，车机主机无法诊断。
- B 类：黑屏但有触摸提示音或蓝牙连接。
- C 类：刷写后黑屏，无启动动画。
- D 类：颠簸、低温或开关门后偶发黑屏。

## 2. 工具
- 诊断仪
- 万用表
- 良品显示屏模组
- LVDS 屏线治具
- 低压稳压电源
- 日志导出工具

## 3. 标准诊断流程
1. 确认用户抱怨并拍照记录屏幕状态。
2. 测量 B+、ACC、GND，记录数值。
3. 主机在线时读取启动日志和版本号。
4. 显示链路异常时，先检查屏线再替换显示屏。
5. 低温或振动相关问题必须复现后再判定根因。
6. 完成维修后执行复测：冷启动、热启动、道路振动或低温复现条件。

## 4. 维修动作
- S006：更换电源管理芯片或主板维修。
- S007：修复端子退针，重新锁止连接器。
- S008：更换显示屏模组，并执行触控/亮度校验。
- S009：维修或更换背光驱动板。
- S010：更换 LVDS 屏线，确认固定卡扣到位。
- S011：定位短路网络，必要时更换主板总成。
- S012：重新刷写完整镜像，校验版本一致性。

## 5. 质量记录要求
维修单必须包含：故障复现条件、至少一项量化检查结果、维修动作、复测结果、版本号或零件批次号。
